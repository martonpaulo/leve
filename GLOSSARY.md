# Glossary

The words Leve and its code use for one thing each.

| Term | Definition | Do not write |
| :--- | :--- | :--- |
| Menu bar status | The text Leve shows in the menu bar for the current or next event of today (`MenuBarStatus`). | title, badge |
| Alert | The full-screen notice Leve shows before an event starts (`AlertPlanner`, `OverlayDisplay`). | popup, banner, reminder |
| Spoken time | The time Leve says aloud at a set interval (`SpokenTime`). | chime, announcement |
| Break | A pause from the screen that `BreakTracker` counts and suggests. | rest, timeout |
| Override | A choice for one event, kept in `OverrideStore` until the event ends. | exception, rule |
| Meeting link | The video-call address Leve finds in an event and opens (`MeetingLink`). | URL, join link |
